**Qly — Mail, intelligently.**  
**巧理 — 重要的，自然在前。**

由 **CEX LIMITED（香港）** 运营的原生 HarmonyOS AI 邮件客户端，支持多邮箱管理、AI 摘要与分类、重点事务整理，以及手机与平板的自适应布局。

## 下载

前往 [Releases](https://github.com/llnode/Qly-AI-Mail-release/releases) 下载最新版本及查看完整功能介绍。

本仓库仅用于发布应用，不提供应用源码。Release 附件只包含**未签名 HAP**，供用户通过轻启使用自己的账户签名后安装。

## 功能概览

- 多账户统一收件箱，支持 Gmail、Microsoft 邮箱及多种 IMAP/SMTP 服务预设，包括 QQ、网易、阿里邮箱与 Yandex Mail；也可自定义服务器配置。
- AI 邮件摘要、收件箱分类与「关注」事务卡片；支持配置兼容 OpenAI 接口的模型服务和自己的 API Key。
- 富文本邮件阅读、历史引用折叠、更早的关联邮件、搜索、标记、回复、回复全部、转发与草稿。
- 可配置同步范围、分批展示邮件，并在本地复用已下载正文、头像与 AI 结果。
- 手机、平板和折叠屏自适应界面，宽屏侧边栏可调宽，支持左右手握持切换与亮暗主题。
- 14 种界面语言，自动匹配设备语言；AI 摘要跟随应用语言。

具体支持范围、安装要求与测试版限制，以对应版本的 Release 说明为准。自建 Exchange 的 EWS / ActiveSync 暂不支持；自行签名版本的华为帐号能力受应用 ID 与签名校验限制。
